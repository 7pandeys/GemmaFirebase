# **App Name**: ClaimWise

## Core Features:

- Claim Creation: Allow the Customer Agent to initiate a new claim by providing basic information.
- Claim Status Check: Enable Customer Agents and Claim Processors to check the real-time status of a claim using its unique identifier.
- Open Claim Retrieval: List and filter all open claims assigned to a specific Claim Processor.
- Intelligent Entity Extraction: Analyze claim descriptions using a gen AI tool that can extract key entities for preliminary verification.
- Automated Information Verification: Simulate internet research of claims data and related entities.
- Claim Status Update: Enable the Claim Processor to update the status of a claim, add notes, and assign to other processors, while displaying guidelines for rules and regulations.
- Dataset Integration: Integrate the data source provided at https://data.mendeley.com/datasets/992mh7dk9y/2 into a usable format for input, allowing claims simulation to train the AI model.

## Style Guidelines:

- Primary color: A calm blue (#64B5F6) to instill trust and reliability in the application.
- Background color: A very light blue (#E3F2FD) that is easy on the eyes.
- Accent color: A complementary orange (#FFB74D) to draw attention to important actions and updates.
- Headline font: 'Space Grotesk' (sans-serif) for a modern and technical feel.
- Body font: 'Inter' (sans-serif) for readability in forms and status updates.
- Use clear and professional icons for claim status, user roles, and actions. Consider using a consistent icon set such as Material Design Icons.
- Maintain a clean and structured layout. Use tabs or a sidebar navigation for different roles (Customer Agent, Claim Processor). Prioritize important information, like claim status and updates.
